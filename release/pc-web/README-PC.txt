SEKAI: Custom Stage — Версия для ПК / Браузера (v1.1.0)
=========================================================

Как запустить на ПК:
1. Просто откройте файл «index.html» двойным кликом в любом браузере
   (Chrome, Edge, Firefox, Safari, Opera) — всё уже встроено внутрь него!

Дополнительно (для установки как отдельное окно / PWA):
- На Windows запустите «Запустить-на-ПК.bat» (или на macOS/Linux: bash start-pc.sh)
  и в адресной строке браузера нажмите «Установить приложение».

Управление на ПК:
- Дорожки: D, F, J, K (переназначаются в Настройках)
- Пауза: Esc (с отсчётом 3·2·1 при возврате)
- Быстрый рестарт: R
